🏆 Enterprise Architecture Showcase

🏗️ [CIS Phase 2: Crowdsourced Ideation](https://github.com/JalaU-Capstones/cis-phase2-crowdsourced-ideation)
Modern .NET 8 Minimal API

A sophisticated backend service implementing Vertical Slice Architecture with ADR (Architecture Decision Records).

Highlights:
- 📐 Vertical Slice Architecture (ADR-004)
- 🗄️ EF Core 8 with best practices (ADR-003)
- 🧪 Comprehensive testing: xUnit + FluentAssertions + Moq (ADR-005)
- 🚀 Production-ready API design

Stack: `C#` `.NET 8` `EF Core` `Minimal APIs` `Vertical Slice`

🔧 [CIS Phase 1: User Management API](https://github.com/JalaU-Capstones/CIS-Fase1-User-Management-API)
Legacy Integration REST API

Enterprise-grade CRUD API designed to coexist with legacy CLI systems, demonstrating real-world integration patterns.

Highlights:
- 🔗 RESTful API with legacy system coexistence
- 👥 Employee user management domain
- 🔄 Migration path from CLI to API architecture
- 📊 Enterprise-grade error handling

Stack: `Java` `Spring Boot` `REST API` `JPA`

🧭 [Pathfinder Suite](https://github.com/JalaU-Capstones/pathfinder-functional-backend)
Full-Stack Pathfinding Platform

A three-repo ecosystem for the Programming 4 module: a functional Node.js backend, a Vue 3 + Vite frontend with an interactive grid and A visualization, and a Python utility suite for validating API requests, exporting PostgreSQL data, and visually verifying algorithm execution.

Highlights:
- 🗺️ Maps, obstacles, waypoints & route calculation
- ⚡ A pathfinding visualization on a live grid
- 🐘 PostgreSQL data export & API validation tooling
- 🧩 Full CRUD across all entities

Stack: `JavaScript` `Vue 3` `Node.js` `Python` `PostgreSQL`

🎮 [Arcade Maze Chomper](https://github.com/JalaU-Capstones/arcade-maze-chomper)
Cross-Platform Game Development

Modern recreation of the classic Pac-Man using .NET 9.0 and Avalonia UI, showcasing cross-platform desktop capabilities.

Highlights:
- 🎯 Cross-platform desktop (Windows/Linux/Mac)
- 🎨 Avalonia UI modern interface
- 🧠 Game loop architecture & state management
- 📦 140MB+ asset management

Stack: `C#` `.NET 9` `Avalonia UI` `Game Dev`
